# P3-NRF52840 v41.3 Stable — Release Notes

## Подтверждено на реальной шторе

- Zigbee End Device (nRF52840 HW-954, endpoint 10), интеграция Zigbee2MQTT.
- Открытие, закрытие, остановка и позиционирование 0–100%.
- Локальная кнопка и аппаратное обучение конечных положений.
- Сохранение конечных положений после отключения питания.
- Zigbee Basic `SWBuildID` (`0x4000`): `41.3`, ответ Dev console: `{"swBuildId":"41.3"}`.
- В Z2M доступны управление шторой и батарея; диагностические и калибровочные поля скрыты.

## Пакет прошивки

Скачивайте только артефакт **P3-NRF52840-v41.3-Stable-UF2** из успешного GitHub Actions запуска, соответствующего коммиту релиза. Сверяйте `SOURCE_COMMIT.txt` и `SHA256SUMS.txt`.

Файл прошивки: `P3-NRF52840-build41-3.uf2`.

## Ограничения

- Zigbee OTA обновление **не поддерживается** в v41.3.
- Измерения тока сна и автономности батареи не проводились.
- Прошивка управляет физическим двигателем; при USB-прошивке отключайте питание мотора и UART.
- После обновления сначала проверьте STOP и движение под наблюдением.
- Автоматическое отображение версии в карточке Z2M пока не реализовано; атрибут читается вручную через Dev console.

## Дальнейшие работы

- Отдельная экспериментальная ветка v42.0: безопасный загрузчик, Zigbee OTA Upgrade cluster, тестирование прерванных обновлений.
- Проверка энергопотребления End Device без изменения стабильного поведения v41.3.
